# 电力负荷与经济活动的解释框架

工业、商业和居民用电共同构成总负荷。工作日生产经营时段的持续性负荷变化，更可能包含企业生产、订单和开工率变化的信息；夜间或节假日的短时波动则更容易受到居民生活、日历和调度因素影响。

# 不能把相关性直接当作因果

总用电量同时受天气、节假日、电价、需求响应、新能源出力、设备检修、产业结构和数据质量影响。任何“经济走强/走弱”判断都必须先排除显著非经济扰动，并检查持续时间、时段分布和多源证据是否一致。

# 经济信号的优先证据

较可信的经济信号通常具备：在生产经营时段出现；持续数日而非单点；天气处于常态区间；节假日与政策事件解释不足；行业或宏观指标方向一致；数据质量正常。只有部分条件满足时，应使用“可能”“需复核”等表述。

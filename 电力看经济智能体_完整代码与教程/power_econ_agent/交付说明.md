# “电力看经济”智能体项目交付说明

## 1. 交付内容

本目录是一个可直接安装、验证、训练和二次开发的完整工程，覆盖：

1. 小时级负荷、气象、宏观、节假日和政策/检修事件的多源获取与统一；
2. 数据质量检查、时间对齐和发布滞后处理；
3. 只使用历史信息的趋势、日周期、周周期和残差多尺度分解；
4. 负荷、天气、日历、宏观、事件/质量五组特征解耦；
5. P10/P50/P90 多步负荷预测、GRU-VAE 异常检测和稳健分数融合；
6. 月度“电力看经济”指标 nowcast；
7. 特征组消融、知识图谱规则和本地 RAG 联合诊断；
8. 感知、诊断、报告、问答四智能体及统一编排器；
9. CLI、FastAPI、Streamlit、MCP 和 SQLite 持久化；
10. 合成演示数据、已训练模型、样例报告、自动测试和一键验收脚本。

## 2. 最快验收（不重新训练）

### Linux / macOS

```bash
cd power_econ_agent
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
pip install -e .
power-econ doctor -c configs/demo.yaml
python scripts/verify_all.py --config configs/demo.yaml
```

### Windows PowerShell

```powershell
cd power_econ_agent
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip setuptools wheel
pip install -e .
power-econ doctor -c configs/demo.yaml
python scripts\verify_all.py --config configs\demo.yaml
```

成功时，`artifacts/outputs/verification_summary.json` 中所有阶段均为 `passed`。

## 3. 从头运行全流程

```bash
power-econ demo -c configs/demo.yaml
```

或逐步执行：

```bash
power-econ collect -c configs/demo.yaml --refresh
power-econ features -c configs/demo.yaml
power-econ train -c configs/demo.yaml
power-econ scan -c configs/demo.yaml --limit 20
power-econ forecast -c configs/demo.yaml
power-econ report 2024-12-01 2024-12-31 -c configs/demo.yaml --max-diagnoses 5
power-econ chat "最近异常是否能够直接说明经济走弱？" -c configs/demo.yaml
```

## 4. 启动软件原型

```bash
# REST API
power-econ serve -c configs/demo.yaml --host 0.0.0.0 --port 8000

# 可视化界面
pip install -e ".[ui]"
power-econ dashboard -c configs/demo.yaml

# MCP 工具服务
pip install -e ".[mcp]"
power-econ mcp -c configs/demo.yaml --transport stdio
```

也可使用 Docker：

```bash
docker compose up --build api
docker compose --profile ui up --build dashboard
```

## 5. 接入真实数据

- 联网获取气象和宏观数据：编辑 `configs/real_data.yaml`；
- 所有数据使用本地 CSV：编辑 `configs/csv_data.yaml`；
- 文件模板：`data/input/*_template.csv`；
- 字段、时间、缺失和发布滞后规则：`docs/真实数据接入规范.md`。

推荐先复制模板，不直接覆盖演示数据：

```bash
cp data/input/load_template.csv data/input/load.csv
cp data/input/weather_template.csv data/input/weather.csv
cp data/input/macro_template.csv data/input/macro.csv
cp data/input/events_template.csv data/input/events.csv
```

然后运行：

```bash
power-econ collect -c configs/csv_data.yaml --refresh
power-econ features -c configs/csv_data.yaml
power-econ train -c configs/csv_data.yaml
python scripts/verify_all.py --config configs/csv_data.yaml
```

## 7. 重要边界

仓库保证的是“工程链路完整、代码可运行、结果可复现”，而不是承诺在未知真实电网数据上天然达到完美精度。真实部署必须使用当地数据重新训练，并由业务专家完成事件标签复核、阈值校准、回测和上线验收。系统输出的是有证据和不确定性的原因候选，不把相关性自动写成确定因果。

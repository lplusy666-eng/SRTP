# 常见问题

## 1. 为什么默认不用大模型也能运行？

异常识别、特征贡献、规则原因和知识检索都由本地代码完成。模板提供器只把结构化结果组织成中文，所以没有 API Key 也能完成诊断、报告和问答。

## 2. 开启 OpenAI 后，大模型会不会替代预测模型？

不会。OpenAI 只参与文字生成，输入是本地计算出的事件、候选原因、特征贡献和知识片段。预测和异常分数不由 LLM 生成。

## 3. 为什么异常 Precision 不高但 ROC-AUC 很高？

演示阈值偏向高召回，因此会产生较多告警。ROC-AUC 评价排序能力，Precision 受固定阈值和异常基率影响。真实项目需要按告警成本、事件级聚合和人工标注重新选择阈值。

## 4. 80% 区间覆盖率为什么不是正好 80%？

P10–P90 是模型估计区间，不会天然精确达到 80%。可增加训练数据、模型容量或在验证集上做 conformal calibration。

## 5. 为什么使用统计编码器而不是大型 Transformer？

本项目优先保证 CPU 可复现、依赖可控和组级解释。上游已经显式做趋势/日/周分解，统计编码器在演示数据上训练快。接口允许替换为 TCN、TFT、PatchTST 等。

## 6. VAE 为什么用 GRU？

VAE 需要建模多变量序列形态，GRU 在短窗口、有限数据和 CPU 环境中较稳定。预测主模型则使用更快的组级统计编码器。

## 7. “特征解耦”是否等于严格因果解耦？

不是。这里是结构化分组、独立编码、正交正则和组消融形成的可解释表示。它提升干扰剥离和诊断能力，但不构成统计因果识别证明。

## 8. 如何证明不是时间泄漏？

代码中趋势、周期和滚动特征都排除当前行；Scaler 只拟合训练集；宏观特征按发布滞后；时间切分不随机；测试标签不参与阈值校准。`tests/test_features.py` 还专门检查宏观发布滞后。

## 9. 如何加入行业用电？

把行业字段加入负荷 CSV，并在 `FeatureBuilder` 增加 `industry` 组。模型会自动建立新分支和门控。

## 10. 如何加入检修和限电日志？

简单场景可转成日级 `events.csv`；小时级场景扩展事件表为 `start_time/end_time`，在 `calendar.py` 区间匹配，并在知识规则中增加原因和证据。

## 11. 为什么报告期可能没有异常？

报告仅统计超过校准阈值且经过时间去重的代表性事件。无异常是合法结果。可先用 `power-econ scan --limit 30` 找到有事件的日期。

## 12. AKShare 失败怎么办？

AKShare 上游接口可能变化。系统会对每个宏观指标独立容错。更稳妥的生产方式是定期下载并固化本地 `macro.csv`。

## 13. Open-Meteo 数据是否等于站点实测？

历史接口主要基于再分析/模型数据。精细业务应优先使用当地气象站或企业自有气象数据，并保留来源说明。

## 14. 能否做实时流式监控？

当前原型按文件/批次运行。生产化可将最新负荷写入时序数据库，每小时调用特征增量计算和 `InferenceEngine`，再通过消息队列推送事件。

## 15. SQLite 能否多用户生产使用？

SQLite 适合单机原型和演示。并发写入、审计和高可用场景应改为 PostgreSQL/TimescaleDB 等。

## 16. 怎样清空事件和报告？

备份后删除对应配置的 `power_econ.db` 和 `reports` 目录。下次启动会自动建表。

## 17. 怎样完全重训？

```bash
power-econ collect -c configs/demo.yaml --refresh
power-econ features -c configs/demo.yaml
power-econ train -c configs/demo.yaml
```

## 18. 怎样只查看随附模型？

```bash
power-econ doctor -c configs/demo.yaml
power-econ forecast -c configs/demo.yaml
python scripts/verify_all.py --config configs/demo.yaml
```

## 19. 真实数据上要多少历史？

最低能训练不等于足够可靠。小时级总负荷建议至少 12 个月以覆盖季节，最好 24–36 个月；nowcast 至少需要 18–24 个月月度目标。

## 20. 能否“完美”判断经济走势？

不能把单一总负荷自动当作经济因果指标。系统的目标是更可靠地剥离天气、日历、政策和质量扰动，给出可审计的候选判断。最终结论仍需分项用电、宏观数据和专家复核。

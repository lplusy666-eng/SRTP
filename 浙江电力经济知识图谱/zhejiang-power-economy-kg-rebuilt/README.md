# 浙江电力—经济—天气—节假日知识图谱（实际数据重建版）

本包用用户提供的浙江省月度用电、三次产业季度数据和国务院节假日安排重建，并补入浙江中部代表点的 ERA5-Land 月值温度特征。

## 数据范围

- 月度用电：2021-01 至 2025-03，共 51 条。
- 三次产业：1997Q1 至 2025Q4，共 348 条。
- 天气：2021-01 至 2025-12，共 60 个月；29.2N、120.2E 代表点。
- 日历：2021-01-01 至 2025-12-31，共 1826 天，包含调休工作日。
- 图谱：241 个基础/时期/事件节点，1179 个观测节点，4775 条关系。

## 重要限制

1. 用电源表没有明确单位。本包保留原始值，并仅以“推断万千瓦时”提供换算列。
2. 天气是浙江中部单点 ERA5-Land 代理，不是全省面积加权平均。适合 SRTP 原型，不能直接代表全省所有地市。
3. Open-Meteo 下载的 XLSX 中降水和风速为 #NUM!，本版没有把错误字段导入图谱；相关指标保留为 planned 节点。
4. 产业增加值是季度累计值，不能与月度单月用电直接做同口径弹性计算。
5. AFFECTS / PROXIES_FOR 为项目先验关系，需后续用统计或因果方法检验。

## 推荐使用顺序

先查看工作簿“使用说明”和“月度融合”，再用 CSV 做建模；需要图数据库时按 neo4j_import.cypher 导入。

## 直接浏览图谱

双击“浙江电力经济知识图谱_交互浏览版.html”即可查看。页面支持核心结构、月度实例、季度实例和全部数据四种视图，并支持缩放、拖动、搜索和节点属性查看。首次打开需要联网加载图形布局组件。

> Neo4j 导入脚本使用 APOC 动态创建关系，执行前请确认已安装并启用 APOC。

### 关键技术决策（后续不要推翻）
1. **循环不认识具体工具**，只调 `dispatch(name, args)` —— 这是与"固定流水线"的分界线
2. **`LLMPlanner` 只定义接缝**：接受 `call_llm(messages, tools)` 回调，已覆盖 OpenAI/Anthropic/dict 三种返回归一化
3. **五段式契约写进类型**：`Conclusion` 用 model_validator 强制 counter_evidence / uncertainty 非空
4. **`submit_conclusion` 作为唯一出口工具**：模型必须通过工具调用提交结论，获得 schema 校验 + 可追溯 + 可评分
5. **缺失数据返回 `available=false` 而非空列表** —— 防幻觉的关键，空列表会被模型理解为"没有异常"
6. **残差 ≠ 同比**：残差接近零时正确结论是"不构成经济信号"，不能顺着用户预设编异常叙事
7. **能力边界显式拒答**：预测类问题、超范围期次直接拒答，且不说"建议补充数据"

### 踩过的坑（重要，避免重犯）
1. **中文全角引号被写成 ASCII 引号** —— 在 Python 字符串里会提前终止字符串，
   一次性搞坏 5 个文件。写中文 docstring/description 时必须确认引号是全角 `“”`
2. **批量修正引号时误伤 `"""`** —— 结束标记 `"""` 被当成"内嵌引号"改成了 `"“"`。
   批量改代码前先想清楚边界条件
3. **列嗅探选中累计值** —— 江苏表里 `consumption_ytd_yi_kwh`（年内累计）与
   `consumption_month_yi_kwh`（当月）并存，累计值单调增长、变异系数更大，
   只按变异度排序会选错。已加 VALUE_PENALTY / VALUE_BONUS / VALUE_PREFERRED 三层打分
4. **规划器跳过失败步骤会死循环** —— 用"假工具名"占位是错的，
   改成 `_skipped` 集合 + `_decide` 返回 None 让调用方重新评估
